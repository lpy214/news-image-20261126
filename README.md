A program that draws a 1024x1024 newspaper front page, "The World Today", summing up Thursday 26 November 2026 in six stories: Kim Jong Un calls for tactical nuclear weapons to be used across many missions (KCNA report, 26 Nov), a third tanker — an LNG carrier — hits a mine in the Strait of Hormuz after two oil tankers did the same on Wednesday, Macy's 100th Thanksgiving Day Parade is postponed to Saturday over a nor'easter, nearly 2,000 migrants reach Spain's Canary Islands in a record single day, Yemen's Houthis threaten Saudi ports after a coalition strike on Hodeidah, and Thanksgiving travel faces long airport lines and bad weather. Pure Python 3 standard library: it rasterises its own hand-drawn 5x7 bitmap font, draws every picture from shapes, and encodes the PNG by hand, so two runs write byte-identical output.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
